# Lego Arduino Train
Software to control a Lego Train Hub using an Arduino Nano ESP32.

## To Build
### Prerequisites
- An Arduino Nano ESP32
- [PlatformIO](https://platformio.org/)

### Building
1. Clone repository (including submodules) with `git clone --recursive https://github.com/IwanIDev/lego-arduino-train.git`
2. Connect Arduino Nano ESP32 via a USB cable
3. Upload code to Arduino with `platformio run --target upload`
